PASS の条件：説明の中に、この変更で結果が変わる具体的な入力例（例：price と qty の値）と、変更前後の値が含まれている。
または、それを示すために追加すべき例を具体的に挙げている。

補足：
- 値は表でも本文でもよい。「手計算」「未検証」と断ってあっても、入力と変更前後の値があれば PASS。
- 値が正しいかは、JavaScript の Math.round（.5 は +∞ 方向へ丸める）と浮動小数点の計算で判断する。例：10.5×1 を 2 行 → 変更前 21、変更後 22。0.1×3 → 変更前 0.30000000000000004、変更後 0。
- 入力例も、追加すべき例も無いときだけ FAIL。
