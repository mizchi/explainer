# evals の結果

## 2026-09-25（claude plugin eval、Claude Code 2.1.282）

- 実行コマンド：`claude plugin eval . --trust-plugin --allow-tools Bash Write Edit Agent -j 4`
- 規模：24 回の実行（5 ケース × プラグインあり・なし）、12 分 26 秒、$6.65
- 判定モデル：haiku（既定）

### この環境の制約：シェルが動かなかった

実行したコンテナでは、eval のサンドボックス内の Bash が起動時に失敗しました（`apply-seccomp: write /proc/self/uid_map: Operation not permitted`）。
bubblewrap と socat は入れましたが、入れ子のコンテナでユーザー名前空間を作れませんでした。
eval はサンドボックスなしでシェルを動かすことを拒否します。それを回避する設定はしていません。

そのため、コードを実行したかどうかを見る grader は、この回の結果では意味を持ちません。
下の表は、それらを**除外して**計算し直した値です（重みは各 grader の `weight`）。

| 除外した grader | 理由 |
|---|---|
| `crash-course/ran-code`, `crash-course/outputs-shown` | Bash が失敗しても `tool_used` は呼び出しを数える。出力は実行されていない |
| `book/ran-answers`, `book/answers-checked` | 同上 |
| `first-reader-no-rewrite` の全体 | first-reader は Python のスクリプトを Bash で動かす。ケースごと無効 |

### 結果（シェルに依存しない grader だけ）

| ケース | 回数/条件 | あり | なし | Δ | 読み方 |
|---|---|---|---|---|---|
| `crash-course` | 2 | 1.00 | 0.50 | **+0.50** | ありは 2 回とも、既知の省略・想定読者の明記・答えつきの理解度チェックを満たした。なしは理解度チェックが 2 回とも無く、1 回は想定読者も既知の省略も無かった |
| `pr-reader-first` | 3 | 0.83 | 0.33 | **+0.50** | ありは 3 回とも、読み手の前提を確かめるか明示した。変更前後の具体的な値は 3 回中 2 回。なしは値を 1 回も示さなかった |
| `one-liner-control` | 3 | 1.00 | 1.00 | 0.00 | 対照。ありでもスキルは 1 度も発火せず、ファイルも作らなかった（過剰発火なし） |
| `book` | 2 | 0.92 | 0.92 | 0.00 | 章の構成（quickstart から始まる、各章に目標と答えつきの問い）は、スキルなしでも満たせた。この grader では差が出ない |
| `first-reader-no-rewrite` | 2 | — | — | — | 無効（上記） |

2〜3 回ずつの実行なので、差は傾向として読んでください。

### 数値に出ない観察：実行できなかったことを報告したか

`crash-course` と `book` の 8 回は、どれも Bash が失敗していました（トレースに `uid_map` のエラーが 1〜5 件）。

- **あり：4 回中 4 回**が、最後の返答で「スクリプトを実行できず、検証できていない」と報告した。
- **なし：4 回中 0 回**。コードと出力を載せた資料を、そのまま完成品として渡した。

スキルの「検証できなかったことは『未検証』と明記する」が、そのまま効いています。
逆に言えば、スキルなしの資料に載っている出力は、実行されていないのに実行結果のように見えます。

### 次に測ること

- **シェルが動く環境で再実行する**（macOS、または unprivileged user namespace が使える Linux）。`ran-code` / `outputs-shown` / `answers-checked` と first-reader のケースは、そこで初めて意味を持つ。
- **`book` の grader を強める**：構成はスキルなしでも満たせるので、スキルが足すもので差を見る。
  - 概念を導入前に使っていないか
  - 演習の出発点が落ちることを確かめたか
- **「実行できなかったことを報告したか」を grader にする**：今回は手でトレースを数えた。
