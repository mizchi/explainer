# TUI で説明するとき：AA（テキストの図）

端末（Claude Code の TUI など）の中で説明を求められたら、HTML や SVG を作らずに、返答の中に AA を置く。
AA は、返答のコードブロック（```` ```text ````）に入れる。等幅で表示され、空白も詰められない。

AA は、端末が 1 文字を何桁に数えるかで崩れる。
全角（日本語）は 2 桁、罫線（─ │ ┌）と ASCII は 1 桁。この数え方を 1 か所でも間違えると、箱の右の辺がずれる。
だから、描いたら必ず端末に描かせて確かめる。

## 手順

```
1. 描くか決める    番号付きの手順・字下げの木（├──）で足りるなら、箱は描かない
2. 描く            下の「描き方」のどれかで。幅は 80 桁以内（全角は 2 桁）
3. 検査する        node <skill>/scripts/aa-check.mjs <file.txt> [--cols 80] [--ascii]
4. 目で見る        出力の look at it: の画像（端末の見た目）を Read で開く
5. 返答に貼る      ✗ が 0 になった AA を、そのまま ```text のブロックに貼る
```

`aa-check.mjs` は、AA を端末エミュレータ（xterm.js）に描かせ、端末が実際に並べた桁の格子で検査する。

| 検査 | 落ちる条件 |
|---|---|
| ✗ wrap | `--cols` より長い行がある（端末で折り返される） |
| ✗ tab | タブがある（端末ごとに幅が違う） |
| ✗ joint | 角・T 字・十字の罫線が、つながるべき隣につながっていない。箱の辺がずれている |
| ✗ ascii | `--ascii` のとき、ASCII 以外の文字で線を引いている |
| △ touch | 文字が、箱の辺ではない線に接している。どの線のラベルか読みにくい |
| △ ambiguous | 全角の文字と罫線が混ざっている。罫線を 2 桁に数える設定の端末（CJK 向けの設定）では崩れる |
| △ emoji | 絵文字がある。端末によって 1 桁か 2 桁かが違う |

△ は落とさないが、画像を見て、直すか決める。

## 描き方

### 1. 箱を描かない（まず考える）

順序は番号付きの手順、構造は字下げの木で足りることが多い。木は罫線（├ └ │）で描いてよい。

```text
docs/formal-methods/
├── README.md      本文（Z3 と TLA+ の「OK」の読み方）
├── checks.json    本文の出力を再生成するコマンド
└── figures/       図と事実シート
```

### 2. D2 から AA を出す（ラベルが ASCII のとき）

D2 は、出力先を `.txt` にすると AA を描く。`--ascii-mode=standard` で ASCII だけ、既定（`extended`）で罫線を使う。

```sh
d2 --ascii-mode=standard flow.d2 flow.txt
node <skill>/scripts/aa-check.mjs flow.txt --ascii
```

- **ラベルに日本語があると崩れる。** D2 v0.9.0 は、全角の字の間に空白を入れ、箱の右の辺をずらした（`aa-check` で joint が 8 か所）。日本語のラベルは D2 の AA に使わない。
- ラベルが ASCII なら、試した 2 つの図（手順・アーキテクチャ）は standard / extended とも ✗ 0 だった。
- ただし、辺のラベルが別の辺の線に接することがある（△ touch）。画像で確かめ、読みにくければ手で直す。

### 3. 手で描く（日本語のラベルを箱に入れるとき）

- 線は ASCII（`+ - | > < v ^`）で描く。罫線より、端末の設定に左右されない。
- 箱の幅は、中の文字の桁数から決める。全角 1 字 = 2 桁。「変更を書く」は 10 桁、左右に空白 1 桁ずつで、中身は 12 桁。
- ラベルは線から 1 桁空ける。
- 描いたら `aa-check.mjs --ascii` に通す。数え間違いは joint で落ちる。

```text
+------------+     +--------------+     +----------+
| 変更を書く | --> | テストを回す | --> | レビュー |
+------------+     +--------------+     +----------+
                      ^         |          |    |
                      |         | 落ちる   |    | 承認
             もう一度 |         v          |    v
                      |      +------+      |  +--------+
                      +----- | 直す | <----+  | マージ |
                             +------+ 指摘    +--------+
```

このリポジトリで使う `mermaid` パッケージは AA を出さない。Mermaid で描く図を端末で見せるなら、D2（ラベルが ASCII のとき）か、手で描く。

## 注意

- 端末の幅が分かっているなら `--cols` をそれに合わせる。分からなければ 80。
- 罫線（─ │ ┌）は、多くの端末で 1 桁だが、CJK 向けの設定（あいまいな幅の文字を 2 桁にする）では 2 桁になる。読み手の端末が分からず、日本語と混ぜるなら、ASCII で描く（`--ascii`）。
- AA は図の代わりであって、資料の代わりではない。長い説明が要るなら、資料（HTML）を作ると伝える。
